# ML Training Portfolio

This repository contains my machine learning practice projects and implementations.

Each project is organized in a separate folder and includes its own README with details about the goal, implementation, and learning points.

I am currently studying machine learning with a focus on Python, NumPy, scikit-learn, TensorFlow, and the core mathematics behind ML algorithms.

---

## Skills Practiced

- Python programming for machine learning
- NumPy-based numerical computation
- Manual implementation of ML algorithms
- Cost function implementation
- Gradient descent
- Feature scaling and normalization
- Polynomial feature engineering
- Regularization
- Binary classification
- Logistic regression
- Basic neural network implementation
- Dense layer logic
- Forward propagation
- Model prediction and evaluation
- Data visualization with Matplotlib
- Using scikit-learn for practical ML workflows
- Using TensorFlow/Keras for neural network training

---

## Technologies Used

- Python
- NumPy

- scikit-learn
- TensorFlow
- Keras

---

## Repository Structure

The repository is organized by topic and project.

Each project folder contains:

- source code;
- project-specific README;
- explanation of the implementation;
- notes about the main learning goals.

---

## Learning Approach

My learning approach is to first implement core algorithms manually in order to understand their internal logic.

After that, I reproduce similar workflows using standard machine learning libraries such as scikit-learn and TensorFlow/Keras.

This helps me connect the mathematical foundation of machine learning with practical development tools.

---

## Goal

My goal is to build a strong foundation in machine learning and apply ML techniques to real-world product, automation, and AI-related problems.

I want to combine machine learning knowledge with software engineering skills to build practical and useful AI-driven solutions.

---

## Notes

These projects are learning-focused and intentionally simple.

The purpose is not to create production-ready systems, but to understand machine learning concepts step by step through implementation.
